Projet solveur pour le jeu "Demain tu m'as tué" jeu de stratégie proche des échecs.
Le but de ce projet est de développer un modèle de réseau de neurones entrainé pour jouer au jeu donc déjà implémenter le jeu numériquement puis créer un modèle pour apprendre à jouer au jeu.
Ce projet permet aussi de développer des compétences graphiques pour rendre le solveur visuellement plaisant.
